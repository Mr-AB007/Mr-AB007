## 🚀 Projects

- **⚡ B2: Personal AI Assistant (Local LLM)** · [Repo](https://github.com/Mr-AB007/b2-personal-ai)
  A private, ChatGPT-style AI chatbot that runs fully on my own PC. It streams answers from **my own versioned model** (`b2:v1` Llama 3.2 → `b2:v2` Qwen3 4B) built with Ollama Modelfiles, with one-command upgrades and rollback. It adds **web search with cited sources (RAG)**, where the model rewrites follow-up questions into search queries, plus personas, chat history and an **"Under the hood" panel** that shows the exact prompt, tokens and speed. The modern animated UI is built in React.
  Technologies used: `Python`, `React`, `Vite`, `Bootstrap`, `Framer Motion`, `Ollama`, `Qwen3`, `RAG`
